# openmat feature scope

openmat is not a complete MATLAB replacement. Simulink is missing. This wiki lists the built-in subset.

MATLAB is a trademark of MathWorks. openmat is not affiliated with MathWorks.

## Areas

- [Language](Language.md)
- [Core, plots, and text](Core.md)
- [Signal Processing](Signal-Processing.md)
- [Control and fixed-point](Control-and-Fixed-Point.md)
- [Search path and packages](Search-Path.md)
- [Hardware in the loop](HIL.md)

Not implemented: `@class` folders, `cwt`, `dwt` ([#43](https://github.com/3NT3RTAiN3R26/openmat/issues/43)). A spectrogram drawn with no output arguments is a magnitude curve, not a heatmap.
